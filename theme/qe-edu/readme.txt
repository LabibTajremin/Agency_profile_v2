A premium, fully editable education and study-abroad theme built for Elementor.

== Description ==

QE Edu is an education / study-abroad theme designed for Elementor. Every text,
colour and section can be changed without code. Install the companion plugin
"QE Edu Core" (included with the theme) for the Theme Settings panel, 12 accent
colour palettes, custom Elementor widgets, content types, forms, SEO and the
one-click demo import.

== Installation ==

1. Appearance → Themes → Add New → Upload Theme → choose qe-edu.zip → Activate.
2. Follow the "required plugins" notice to install Elementor and QE Edu Core.
3. Theme Settings → Tools → Import demo.
